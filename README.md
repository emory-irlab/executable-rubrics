## ExecRubrics: Executable Tool-Augmented Rubrics for Verifiable and Efficient Long-Form Evaluation

ExecRubrics ([paper](https://arxiv.org/abs/2608.22559)) has been accepted to EMNLP Findings 2026!

This repository contains the prompts and code to generate executable rubrics, as well as the tools used to generate tool augmented executable rubrics.

If you have any ideas of useful extensions, feel free to reach out over email.
